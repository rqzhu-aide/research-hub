# Archived phase playbooks

Playbooks from earlier workflow designs, kept for reference only. Nothing in
the application reads this directory; the active phase playbooks live in
`config/phases/<slug>/`.

| Directory | Superseded design |
|---|---|
| `04-numerical-validation-v1-sequential-protocol/` | Sequential numerical-validation phase with the hardcoded protocol checkpoint (Phase 04 is now parallel Draft Assembly; checkpoints are config opt-in) |
| `05-data-analysis-v1-debate/` | Debate-style scientific-interpretation phase (Phase 05 is now sequential Review & Revision) |
| `06-paper-writing-v1/` | Standalone paper-writing phase, removed from the default workflow (draft review is covered by Phase 05) |
